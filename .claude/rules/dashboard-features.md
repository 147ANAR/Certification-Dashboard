# Dashboard Features

- **4 Stat Tiles**: Active, Time to Renew, Expired, Resigned — with animated counters
- **3D Pie Chart**: Certification distribution by type
- **Line Chart**: Monthly certification trend (Active, Expiring Soon, Expired)
- **Summary Table** (left): Certification counts by type
- **Records Table** (center): Full records with search and CSV export
