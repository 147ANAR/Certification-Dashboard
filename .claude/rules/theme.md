# Theme: Serene Gradient UI

- White/pastel gradient background with soft color wash
- Accent colors: violet (#8b5cf6), fuchsia (#d946ef), rose (#f43f5e), indigo (#6366f1)
- Frosted glass card style with gentle gradient headers
- Gradient icon buttons with soft drop shadows
- Pastel gradient status badges
- Compact layout designed to fit on a single viewport
